## В этом архиве предоставлены файлы прошивок которые были извлечены из приложения flipsky ESC Tool для windows
### (версия 1.5 20250511 (SHA256 6aff4ac60b4d0ed872b23acb397f53c5942622948f8dbfcbd0bc2a2a919b73b4)
Только несколько файлов были открыты мной через дисассемблер, все остальные предоставляются КАК-ЕСТЬ.
У некоторых файлов прошивок есть дополнительные индексы (EB, DR, RC), их значение неизвестно.
Для того что бы попробовать извлечь файлы самостоятельно используйте команду:
` python3 search.py flipsky_esc_tool.exe `

Я вручную просмотрел каждый файл в hex-редакторе и убедился что он является прошивкой, в репозитории только те файлы которые похожи на прошивку для ARM Cortex.


## This archive contains firmware files extracted from the Flipsky ESC Tool application for Windows
### (version 1.5 20250511 (SHA256 6aff4ac60b4d0ed872b23acb397f53c5942622948f8dbfcbd0bc2a2a919b73b4)
Only a few files were opened by me through a disassembler, all others are provided AS-IS.
Some firmware files have additional indices (EB, DR, RC), their meaning is unknown.
To try extracting the files yourself, use the command:
` python3 search.py flipsky_esc_tool.exe `

I manually reviewed each file in a hex editor and verified that it is indeed firmware, the repository contains only those files that resemble ARM Cortex firmware.
